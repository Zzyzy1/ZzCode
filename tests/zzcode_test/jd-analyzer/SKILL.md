# JD Analyzer — 职位描述分析技能

## 概述

本技能用于系统化分析招聘职位描述（Job Description），帮助快速理解职位核心要求、职责范围、任职资格和公司信息，并生成结构化的分析报告。

## 分析步骤

### 第 1 步：提取基本信息

从 JD 中提取以下基础字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| 职位名称 | 岗位全称 | 高级 Java 开发工程师 |
| 公司名称 | 招聘公司 | 某某科技有限公司 |
| 工作地点 | 城市/区域 | 北京·海淀 |
| 薪资范围 | 如有则提取 | 25K-40K/月 |
| 发布时间 | 发布日期 | 2025-01-15 |

### 第 2 步：分析核心职责

列出该职位的 **主要工作职责**，按优先级排序：

1. 识别每个职责的关键动词（如：负责、参与、主导、优化）
2. 区分日常职责 vs 项目型职责
3. 标注职责的难度等级（核心/重要/辅助）

### 第 3 步：分析任职要求

将要求分为以下几类：

- **硬性要求**（必须满足）：学历、工作经验年限、特定技术栈
- **软性要求**：沟通能力、团队协作、抗压能力
- **加分项**：特定证书、大厂经验、开源贡献
- **技术栈清单**：列出所有提到的技术、工具、框架

### 第 4 步：生成分析报告

输出结构化的 Markdown 报告：

```markdown
## 📋 JD 分析报告

### 基本信息
- **职位**：{职位名称}
- **公司**：{公司名称}
- **地点**：{工作地点}
- **薪资**：{薪资范围}
- **发布时间**：{发布时间}

### 🎯 核心职责
1. {职责1}
2. {职责2}
...

### 📚 任职要求
#### 硬性要求
- {要求1}
- {要求2}

#### 软性要求
- {要求1}

#### 加分项
- {加分项1}

#### 技术栈
| 类别 | 技术 |
|------|------|
| 后端 | Java, Spring Boot |
| 前端 | Vue.js |
| 数据库 | MySQL, Redis |

### ⚡ 关键洞察
- **匹配难度**：⭐⭐⭐（中等）
- **核心关键词**：{关键词列表}
- **建议关注点**：{建议}
```

### 第 5 步：给出建议

基于分析结果，提供：

- **求职建议**：如何针对该 JD 优化简历
- **技能差距分析**：JD 要求 vs 常见候选人能力
- **面试准备方向**：可能考察的技术点和项目经验

## 使用示例

**输入：**
> 某公司招聘"高级 Python 后端工程师"，要求 3-5 年经验，熟悉 Django/Flask，掌握 MySQL 和 Redis，有微服务经验优先。

**输出：** 结构化分析报告（见第 4 步模板）

## 注意事项

1. 如果 JD 信息不完整，在报告中标注"未提供"
2. 薪资范围如为面议，标注为"面议"
3. 区分"优先考虑"和"必须满足"的要求
4. 技术栈中注意版本号信息（如有）
5. 对于英文 JD，保留原文关键术语并附中文翻译
