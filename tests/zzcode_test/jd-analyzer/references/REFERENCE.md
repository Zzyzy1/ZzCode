# JD Analyzer 参考文档

## 常见 JD 分析维度

### 1. 职位级别判断
| 级别 | 经验要求 | 典型职责 |
|------|---------|---------|
| 初级 | 1-3 年 | 执行具体任务，在指导下工作 |
| 中级 | 3-5 年 | 独立完成任务，参与方案设计 |
| 高级 | 5-8 年 | 主导模块设计，指导初级成员 |
| 专家/架构 | 8+ 年 | 技术决策，架构设计，团队建设 |

### 2. 薪资参考范围（一线城市）
| 级别 | 月薪范围 |
|------|---------|
| 初级 | 10K-20K |
| 中级 | 20K-35K |
| 高级 | 35K-50K |
| 专家 | 50K-80K+ |

### 3. 常见 JD 关键词分类

#### 技术类
- 后端：Spring Boot, Django, Node.js, Go, Rust
- 前端：React, Vue.js, Angular, TypeScript
- 数据：MySQL, Redis, MongoDB, Elasticsearch
- 运维：Docker, K8s, CI/CD, AWS/Azure/GCP

#### 软技能类
- 沟通能力、团队协作、问题解决、学习能力
- 抗压能力、时间管理、项目管理

#### 公司描述类
- "扁平化管理" → 可能意味着较少层级
- "弹性工作" → 可能需要加班
- "快速发展" → 可能工作强度大
- "期权" → 初创公司
